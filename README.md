# InAmigos_Website

A modern and responsive NGO awareness website developed for **InAmigos Foundation** as part of my internship using **HTML** and **CSS**.  
The website highlights the foundation’s mission, impactful projects, social initiatives, credentials, volunteer opportunities, and contact details through a clean and user-friendly interface.

---

## ✨ Features

- 🌟 Modern and responsive UI design
- 📱 Mobile-friendly layout
- 🏛 About Us section
- 💚 Our Causes section with impactful projects
- 📊 Social Impact statistics
- 🏆 Credentials & recognitions section
- 🤝 Join Us / Volunteer section
- 🌐 Footer with quick links and social media
- 🎨 Smooth hover effects and gradients
- 🔗 Navigation bar with smooth scrolling

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Glassmorphism UI Effects
